MaxTest — программа для тестирования и аттестации сотрудников на компьютере с Windows

Программа для проверки знаний сотрудников на одном компьютере. Без интернета, без сервера, без передачи данных на чужие серверы.

Создавайте тесты любого объёма, проводите проверку знаний на рабочем месте и получайте протоколы — не отправляя ни фамилии, ни результаты в облачные анкеты.

О программе

Что это и для кого

MaxTest закрывает обычную задачу отдела кадров и службы охраны труда: провести плановую проверку знаний, получить протокол и понять, какие темы в коллективе проседают. Всё происходит на одном рабочем компьютере.

Администратор собирает тест в конструкторе — с картинками, разделами и правилами оценивания. Сотрудник садится за тот же компьютер, выбирает себя в списке и проходит тест. Результат сохраняется сразу, отчёт выгружается в Excel одной кнопкой.

  • Данные не покидают компьютер. Ни при создании теста, ни при прохождении, ни при выгрузке отчёта.
  • Файл теста самодостаточен. Картинки лежат внутри файла — тест переносится на флешке одним файлом.
  • Сбой не теряет попытку. Прогресс пишется каждые 15 секунд, после аварийного завершения программа предложит продолжить с того же вопроса.
  • История аттестаций накапливается. Результаты за всё время лежат в одной базе, сотрудников не удаляют, а скрывают.

Интерфейс

Как выглядит

Интерфейс рассчитан на того, кто не изучает программу заранее: подписи вместо иконок, крупный шрифт на экране прохождения, никаких скрытых меню.

Руководство

От установки до протокола

Шесть шагов по порядку — от первого запуска до готового отчёта для отдела кадров.

Установка

Запустите MaxTest-Setup-1.0.0.exe. Мастер спросит согласие с лицензией, папку установки, нужны ли ярлыки на рабочем столе и в меню «Пуск», и предложит сразу задать PIN-код администратора.

Права администратора не нужны: по умолчанию программа ставится в профиль пользователя. Если антивирус насторожился — добавьте папку в исключения, установщик не подписан сертификатом.

Проверка файла до запуска

Убедиться, что установщик скачался целиком и не подменён, можно командой certutil -hashfile MaxTest-Setup-1.0.0.exe SHA256 — результат должен совпасть с контрольной суммой в начале страницы.

Проверка после установки

Выполните в папке программы MaxTest.exe --selfcheck. Ответ «ИТОГ: всё в порядке» означает, что плагины на месте и папка данных доступна для записи.

Список сотрудников

Главное окно → Сотрудники → «Добавить». ФИО, должность, подразделение. Список нужен, чтобы люди не вводили себя вручную перед каждым тестом и в отчёте не появились «Иванов И.И.», «Иванов Иван» и «иванов и и» как три разных человека.

Уволившихся не удаляют, а скрывают: иначе пропадёт история их прошлых аттестаций.

Создание теста

Главное окно → Конструктор тестов. Введите название, нажимайте «+ Вопрос» и заполняйте: тип, вес, раздел, текст, при необходимости картинку и пояснение для разбора ошибок.

Внизу окна идёт постоянная проверка теста. Красная строка — вопрос нельзя нормально оценить, жёлтая — предупреждение. Клик по строке открывает проблемный вопрос. Клавиша F5 показывает предпросмотр — вопрос глазами сотрудника.

Тест сохраняется одним файлом .qtest: картинки внутри, переносить их отдельно не нужно.

Настройки теста

Меню «Тест» → «Настройки теста». Три вкладки:

  • Прохождение — перемешивание, сколько вопросов задавать, ограничение времени, разрешён ли возврат назад, показывать ли сотруднику его результат.
  • Оценивание — правило для вопросов с несколькими ответами, ручная проверка текстовых ответов, шкала оценок.
  • Разделы — темы теста. Удаление раздела не удаляет вопросы: они станут «вне разделов».

Отбор «по N из каждого раздела» имеет смысл, когда вопросов в банке заметно больше, чем задаётся: тогда у каждого сотрудника свой набор.

Проведение

Главное окно → Пройти тест. Программа покажет список готовых тестов из своей папки и недавно открытых; файл с флешки открывается кнопкой «Открыть файл…».

Сотрудник выбирает себя в списке и нажимает «Начать». После завершения окно закрывается, результат сохраняется автоматически, следующий человек начинает с того же шага.

Если компьютер выключился

При следующем запуске программа сама предложит продолжить прерванную попытку с того же вопроса. Потеряется максимум один ответ.

Результаты и отчёт

Главное окно → Результаты. Отфильтруйте нужный тест, период и сотрудников, при необходимости оставьте только не сдавших. Двойной щелчок по строке открывает подробный разбор попытки.

«Выгрузить в Excel» сохраняет книгу из четырёх листов: сводная по попыткам, каждый ответ отдельной строкой, проценты по разделам и список вопросов, на которых чаще всего ошибались.

Если в тесте были развёрнутые ответы, на главном экране загорится Проверка ответов со счётчиком: там их читают и решают, засчитывать ли. Балл, процент и оценка пересчитываются сразу.

Справочник

Типы вопросов

ТипКак заполняется и как оценивается
Один правильный ответ Варианты и отметка напротив верного. Балл начисляется целиком или не начисляется.
Несколько правильных Отмечаются все верные варианты. Оценивается «всё или ничего» либо частично — по настройке теста.
Ввод текста Каждая строка в поле «Правильные ответы» — отдельный допустимый вариант, а не продолжение предыдущего. Для описаний включается многострочное поле ввода.
Установление соответствия Пары «левая часть — правая часть». При прохождении правые части перемешиваются, балл считается за каждую верную пару.
Упорядочивание Пункты записываются в правильном порядке, при прохождении перемешиваются. Оценивается доля правильно расставленных соседних пар.
Флажок «не перемешивать»

Нужен для вариантов вроде «Все перечисленное» и «Ничего из перечисленного»: перемешанные, они оказываются в середине списка и теряют смысл.

Как это работает

Как считается балл

Максимум считается по вопросам, которые сотрудник реально увидел. Если из банка в 50 вопросов задаются 10, максимум — это сумма весов этих десяти, а не всего банка.

Частичный балл за несколько ответов

Доля верно отмеченных минус доля лишних, но не ниже нуля:

балл = вес × max(0, верные / всего_верных − лишние / всего_неверных)

Из формулы следует полезное свойство: стратегия «отметить всё подряд» даёт ровно ноль, а не половину балла.

Текстовые ответы

По умолчанию сравнение нормализованное: регистр, лишние пробелы, «ё» вместо «е», десятичная запятая и точка в конце не влияют на результат. Незасчитанный верный ответ подрывает доверие к тесту сильнее, чем засчитанный лишний, поэтому вариантов лучше перечислить больше.

Оценка

Процент округляется до целого, затем выбирается наибольший порог шкалы, который его не превышает. Пороги задаются целыми процентами — так на границе «70 %» не возникает расхождений из-за дробной арифметики.

Эксплуатация

Данные и резервные копии

Всё лежит в папке %APPDATA%\MaxTest — рядом с программой не создаётся ни одного файла, поэтому её можно ставить и в защищённые от записи папки.

results.dbВсе результаты аттестаций. Главный файл
backup\Копии базы: одна в сутки, хранятся 30 последних
tests\Папка тестов по умолчанию — её содержимое попадает в список выбора
progress\Незавершённые попытки, появляются и исчезают сами
logs\Журнал работы; сюда попадают все необработанные ошибки
security.jsonPIN-код администратора — хранится хешем, не открытым текстом
Своя копия

После каждой аттестации копируйте results.db на флешку или в сетевую папку. Автоматические копии лежат на том же диске и от его отказа не спасают.

Честно

Чего программа не делает

Эти ограничения приняты сознательно — чтобы не создавать ложного ощущения защищённости.

  • Не блокирует компьютер во время теста. Alt+Tab и браузер доступны: защита от списывания здесь организационная, а не техническая.
  • Не проверяет, кто сидит за компьютером. Сотрудник выбирает себя из списка сам.
  • Не шифрует файл теста. .qtest — это zip-архив: тот, кто найдёт его на диске, может прочитать правильные ответы в обход программы. PIN-код закрывает разделы программы, но не файлы. Если это важно — не храните тесты на экзаменационном компьютере, приносите их на флешке.
  • Не работает по сети. Одна машина, одна база. Результаты с нескольких компьютеров придётся объединять вручную.

Вопрос — ответ

Частые вопросы

Нужен ли интернет для работы программы?

Нет. MaxTest полностью работает офлайн: и создание тестов, и прохождение, и отчёты. Программа не отправляет данные на внешние серверы — результаты аттестаций остаются на вашем компьютере.

Сколько стоит программа?

Ничего. MaxTest распространяется бесплатно по лицензии MIT: её можно использовать в коммерческой организации, ставить на любое число компьютеров, копировать и изменять.

Нужны ли права администратора для установки?

Нет. По умолчанию программа устанавливается в профиль пользователя. Если запустить установщик от имени администратора, можно поставить её для всех пользователей компьютера.

Сколько вопросов может быть в тесте?

Ограничения нет. Можно собрать банк из сотен вопросов и задавать каждому сотруднику случайную выборку — например, по десять вопросов из каждого раздела.

Какие типы вопросов поддерживаются?

Пять: один правильный ответ, несколько правильных, ввод текста, установление соответствия и упорядочивание. К любому вопросу можно добавить картинку — схему, фотографию оборудования, знак безопасности.

Где хранятся результаты аттестаций?

В базе SQLite в папке %APPDATA%\MaxTest на том же компьютере. Копия базы делается автоматически раз в сутки, хранятся тридцать последних. Отчёт выгружается в Excel.

Что будет, если компьютер выключится посреди теста?

Ничего страшного: прогресс сохраняется каждые пятнадцать секунд и после каждого ответа. При следующем запуске программа предложит продолжить попытку с того же вопроса.

Можно ли закрыть от сотрудников правильные ответы?

Да. PIN-код закрывает конструктор тестов, результаты, проверку ответов и справочник сотрудников — доступным остаётся только прохождение теста. При запуске тестирования разделы блокируются сразу.

Подходит ли программа для аттестации по охране труда?

Да, это основной сценарий: вопросы с картинками (знаки, схемы, средства защиты), разделы по темам, весовые коэффициенты, гибкая шкала оценок и протокол по каждому сотруднику с разбором ошибок.

Работает ли MaxTest в Windows 11?

Да. Программа собрана для 64-битных Windows 10 и Windows 11. Устанавливать Python или что-либо ещё не нужно — всё внутри установщика.
