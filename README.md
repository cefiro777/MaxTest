# MaxTest

Локальное ПО для аттестации сотрудников. Работает на одном компьютере под
Windows 10, без сети и без передачи данных куда-либо.

Состояние: **все 7 фаз плана выполнены** — план и отметки о приёмке в
[PLAN.md](PLAN.md). Инструкции: [администратору](docs/АДМИНИСТРАТОРУ.md),
[сотруднику](docs/СОТРУДНИКУ.md).

## Запуск из исходников

```powershell
python -m venv .venv
.venv\Scripts\pip install -r requirements-dev.txt
.venv\Scripts\python -m maxtest
```

## Тесты

```powershell
.venv\Scripts\python -m pytest
```

## Сборка релиза

```powershell
.venv\Scripts\python -m tools.build_release
```

Скрипт по шагам: иконка → демо-тест → сборка PyInstaller → **проверка
собранного** (`--selfcheck`) → компиляция установщика Inno Setup. Непроверенная
сборка в установщик не попадает.

На выходе:

| Файл | Что это |
|---|---|
| `dist\MaxTest-Setup-1.0.0.exe` | Установщик, ~28 МБ — это и отдаётся заказчику |
| `dist\MaxTest\` | Распакованное приложение, ~98 МБ (можно копировать вручную) |

Требуется [Inno Setup 6](https://jrsoftware.org/isdl.php). Собрать только
приложение, без установщика: `.venv\Scripts\pyinstaller build\maxtest.spec --noconfirm`.

Установщик спрашивает лицензию (MIT), папку, ярлыки и PIN-код; ставится без прав
администратора; удаление — через «Приложения и возможности», данные аттестаций
при удалении сохраняются, если явно не согласиться их стереть.

## Где что лежит

| Путь | Что это |
|---|---|
| `maxtest\core\` | Модель, формат `.qtest`, оценка, хранилище. Без PyQt — покрыто тестами |
| `maxtest\ui\` | Окна: стартовое, конструктор, проигрыватель |
| `samples\demo.qtest` | Демо-тест (`python -m tools.make_demo` пересобирает) |
| `%APPDATA%\MaxTest\` | Результаты (`results.db`), бэкапы, логи, папка тестов |

Папку данных можно переопределить переменной окружения `MAXTEST_DATA_DIR`.

## Что уже работает

* Формат теста `.qtest` (zip: `manifest.json` + `media/`), атомарное сохранение
* Конструктор: 5 типов вопросов, картинки с автоматическим ресайзом,
  дублирование, порядок вопросов, предпросмотр, панель проверки теста
* Настройки теста: перемешивание, отбор вопросов, разделы, время, шкала оценок
* Прохождение: таймер с авто-сдачей, возврат к прошлым вопросам, перемешивание
* Восстановление после сбоя: прогресс пишется каждые 15 секунд
* Справочник сотрудников (скрытие вместо удаления)
* Оценка: все 5 типов, частичный балл, веса, разделы, произвольная шкала
* Ручная проверка текстовых ответов с пересчётом балла и оценки
* Результаты: фильтры по тесту, сотруднику и датам, разбор попытки
* Отчёт в Excel: сводная, по вопросам, по разделам, сложные вопросы
* SQLite, ежедневный автобэкап базы и копия по требованию
* PIN-код на конструктор, результаты, проверку ответов и справочник сотрудников
* Развёрнутые текстовые ответы (многострочное поле) и окно поддержки проекта
* Сборка в `.exe` без Python на целевом компьютере, диагностика `--selfcheck`

## Что осталось проверить руками

Запуск с флешки на рабочем ПК, реакция корпоративного антивируса, читаемость
интерфейса при масштабе экрана 125 %. Эти пункты нельзя закрыть автотестом.
