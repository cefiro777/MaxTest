# MaxTest — инструкция администратора

Программа для аттестации сотрудников. Работает на одном компьютере, **никуда
не передаёт данные и не требует интернета**. Все результаты хранятся локально.

---

## 1. Установка

Запустите **MaxTest-Setup-1.0.0.exe** и следуйте шагам мастера:

1. **Лицензия** — MIT, свободное распространение. Программу можно ставить на
   любое число компьютеров, в том числе в коммерческой организации.
2. **Папка установки** — по умолчанию в профиль пользователя, права
   администратора не нужны. Если запустить установщик от имени администратора,
   можно поставить программу для всех пользователей компьютера.
3. **Ярлыки** — на рабочем столе и в меню «Пуск», обе галочки на ваш выбор.
4. **PIN-код администратора** — можно задать сразу. Оставьте поля пустыми,
   чтобы задать код позже в главном окне. Забытый PIN восстановить нельзя.

Права администратора не требуются. Интернет не требуется.

Если антивирус ругается на незнакомую программу — добавьте её в исключения.
Установщик не подписан сертификатом, для корпоративных антивирусов этого
достаточно, чтобы насторожиться.

**Проверка после установки.** Откройте командную строку в папке программы и
выполните:

```
MaxTest.exe --selfcheck
```

Должно быть написано «ИТОГ: всё в порядке». Если вместо этого сказано, что нет
JPEG или PNG — картинки в тестах показываться не будут, сборка повреждена.

### Обновление

Запустите установщик новой версии поверх старой — папку выбирать не нужно,
он найдёт установленную программу сам. Результаты, тесты и PIN-код при
обновлении сохраняются.

### Удаление

«Параметры → Приложения → MaxTest → Удалить», либо ярлык **Удалить MaxTest**
в меню «Пуск». Программа спросит, удалять ли данные:

- **Нет** (по умолчанию) — результаты аттестаций, тесты, резервные копии и
  PIN-код останутся в `%APPDATA%\MaxTest`. Их подхватит следующая установка.
- **Да** — всё будет удалено безвозвратно.

## 2. Где лежат данные

Всё в папке `%APPDATA%\MaxTest` (обычно
`C:\Users\<пользователь>\AppData\Roaming\MaxTest`):

| Папка / файл | Что внутри |
|---|---|
| `results.db` | **Все результаты аттестаций.** Главный файл |
| `backup\` | Автоматические копии базы (одна в сутки, хранятся 30 последних) |
| `tests\` | Папка по умолчанию для файлов тестов `.qtest` |
| `progress\` | Незавершённые попытки (появляются и исчезают сами) |
| `logs\` | Журнал работы — пригодится, если что-то пошло не так |

Резервная копия делается автоматически при каждом запуске программы, но не
чаще раза в сутки. **Раз в год после аттестации скопируйте `results.db` на
флешку или в сетевую папку** — это единственный экземпляр ваших данных.

## 2а. PIN-код: закрыть разделы от сотрудников

Пока PIN не задан, любой, кто открыл программу, может зайти в конструктор и
увидеть правильные ответы. Внизу главного окна есть кнопка **Задать PIN**.

После установки кода под PIN уходят четыре раздела: **Конструктор тестов**,
**Результаты**, **Проверка ответов**, **Сотрудники**. Раздел **Пройти тест**
остаётся открытым — он и нужен сотруднику.

Как это работает на практике:

- код спрашивается один раз, после чего разделы открыты **15 минут**, чтобы вы
  не вводили его при каждом переходе между конструктором и отчётами;
- при запуске тестирования разделы закрываются **сразу** — за компьютер
  садится сотрудник;
- кнопка **Заблокировать** внизу окна закрывает разделы немедленно;
- после пяти неверных попыток окно ввода закрывается.

**Забытый PIN восстановить нельзя.** Снять защиту можно только удалением файла
`security.json` из папки `%APPDATA%\MaxTest` — то есть тем, у кого есть доступ
к этой папке.

**Границы этой защиты — важно понимать.** PIN закрывает разделы программы, но
не сами файлы. Файл теста `.qtest` — это переименованный zip: тот, кто найдёт
его на диске и знает про это, прочитает правильные ответы в обход программы.
Если такой риск существенен, дополните PIN организационными мерами:

- не храните файлы тестов на экзаменационном компьютере — приносите их на
  флешке и забирайте после аттестации;
- заведите для аттестации отдельную учётную запись Windows без прав на чтение
  папки с тестами и базой.

## 3. Как создать тест

1. Главное окно → **Конструктор тестов**.
2. Введите название теста.
3. Кнопка **+ Вопрос** добавляет вопрос. Для каждого вопроса задаются:
   - **Тип** — от него зависит вид формы ниже;
   - **Вес** — сколько баллов стоит вопрос (по умолчанию 1);
   - **Раздел** — если разделы заданы в настройках теста;
   - **Текст вопроса** и, при необходимости, **картинка**;
   - **Пояснение** — показывается при разборе ошибок.

### Типы вопросов

| Тип | Как заполнять |
|---|---|
| Один правильный ответ | Варианты + точка напротив правильного |
| Несколько правильных | Варианты + галочки напротив всех правильных |
| Ввод текста | Каждая строка — отдельный допустимый вариант ответа. Галочки «Развёрнутый ответ» и «Проверять вручную» |
| Установление соответствия | Пары «левая часть ↔ правая часть» |
| Упорядочивание | Пункты в **правильном** порядке сверху вниз |

Флажок **«не перемешивать»** у варианта нужен для ответов вроде
«Все перечисленное» — иначе при перемешивании они окажутся в середине списка и
потеряют смысл.

### Развёрнутые ответы

В поле «Правильные ответы» **каждая строка — самостоятельный допустимый
вариант** («220», «220 В», «220 вольт»), а не продолжение одного длинного
ответа.

Если ответ предполагается развёрнутым (описать порядок действий), включите
галочку **«Развёрнутый ответ — поле ввода на несколько строк»**: сотрудник
получит большое поле вместо одной строки. Такой вопрос обычно имеет смысл
сочетать со сравнением «ответ содержит эталон» и ручной проверкой.

### Картинки

Кнопка **Выбрать картинку…**. Изображение автоматически уменьшается и
сохраняется внутрь файла теста — переносить картинки отдельно не нужно.
Файл `.qtest` самодостаточен: скопировали на другой компьютер — картинки на
месте.

### Проверка теста

Внизу окна — панель **Проверка теста**. Красное «⛔» — ошибка, из-за которой
вопрос нельзя нормально оценить; жёлтое «⚠» — предупреждение. Щелчок по строке
переводит к проблемному вопросу. Сохранять тест с замечаниями можно, но перед
аттестацией список лучше очистить.

Кнопка **Предпросмотр** (или F5) показывает вопрос так, как его увидит
сотрудник, — уже с перемешанными вариантами.

## 4. Настройки теста (меню «Тест» → «Настройки теста»)

**Прохождение**
- *Перемешивать вопросы / варианты* — чтобы соседи не списывали друг у друга.
- *Какие вопросы задавать* — все, случайные N из банка, или по N из каждого
  раздела. Второй и третий варианты требуют, чтобы вопросов в банке было
  заметно больше, чем задаётся.
- *Время на весь тест* — 0 означает «без ограничения». По истечении тест
  сдаётся автоматически с теми ответами, которые успели дать.
- *Разрешить возвращаться* — можно ли пересматривать предыдущие вопросы.
- *Показывать сотруднику его результат* — если снять, человек увидит только
  «Тест завершён».

**Оценивание**
- *Вопросы с несколькими ответами*: «частичный балл» честнее, «всё или ничего»
  строже. При частичном балле включённый штраф за лишние варианты не даёт
  выехать на стратегии «отметить всё» — она даёт ровно ноль.
- *Текстовые ответы помечать для ручной проверки* — общая настройка для всего
  теста. У каждого вопроса с вводом текста есть своя галочка «Проверять ответ
  на этот вопрос вручную»: она важнее общей настройки. Так развёрнутый ответ
  можно отправить на проверку, а короткий («220») оставить автомату.
  Помеченные ответы попадут в раздел «Проверка ответов» на главном экране.
- *Шкала* — «Зачёт / незачёт», пятибалльная или своя. Пороги задаются целыми
  процентами; должен быть порог от 0 %, иначе низкому баллу не достанется
  оценки.

**Разделы** — нужны для отбора вопросов по темам и для подсчёта результата по
темам в отчёте. Удаление раздела не удаляет вопросы: они станут «вне разделов».

## 5. Проведение аттестации

1. Заранее заведите людей: главное окно → **Сотрудники** → *Добавить*.
   Сотрудников не удаляют, а скрывают — иначе пропадёт история прошлых лет.
2. Главное окно → **Пройти тест** → выберите файл `.qtest`.
3. Сотрудник выбирает своё ФИО из списка и нажимает **Начать**.
4. После завершения окно закрывается, результат сохраняется автоматически.
   Следующий человек начинает с шага 2.

Если компьютер выключился или программа закрылась посреди теста — при
следующем запуске MaxTest сам предложит продолжить с того же вопроса. Прогресс
сохраняется каждые 15 секунд.

## 6. Результаты и отчёты

Главное окно → **Результаты**.

- Фильтры сверху: тест, сотрудник, диапазон дат, «только не сдавшие».
- Двойной щелчок по строке (или кнопка **Разбор попытки**) открывает подробный
  разбор: что спросили, что человек ответил, что было правильно, пояснение.
- **Выгрузить в Excel** сохраняет книгу из четырёх листов:
  *Сводная* — по одной строке на попытку;
  *По вопросам* — каждый ответ отдельной строкой;
  *По разделам* — процент по темам;
  *Сложные вопросы* — где ошибались чаще всего (самое полезное для обучения).
- **Резервная копия базы** делает копию `results.db` прямо сейчас.

Если включена ручная проверка текстовых ответов, на главном экране появится
кнопка **Проверка ответов (N)**. Там для каждого ответа есть «Засчитать» и «Не
засчитывать»; балл, процент и оценка пересчитываются сразу.

## 7. Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| Программа не запускается | Запустите `MaxTest.exe --selfcheck` из командной строки |
| Вместо картинок пусто | То же; если сказано «JPEG: НЕТ» — сборка повреждена, перекопируйте папку |
| «Не удалось сохранить отчёт» | Файл открыт в Excel — закройте его и повторите |
| Не сохраняются результаты | Нет прав на запись в `%APPDATA%` — проверьте `--selfcheck` |
| Странная ошибка | Посмотрите `%APPDATA%\MaxTest\logs\maxtest.log` |
| Удалили попытку по ошибке | Возьмите базу из `%APPDATA%\MaxTest\backup\` |

---

## 8. Чего программа сознательно не делает

- **Не блокирует компьютер во время теста.** Alt+Tab и браузер доступны —
  защита от списывания здесь организационная, а не техническая.
- **Не проверяет, кто сидит за компьютером.** Сотрудник выбирает ФИО сам.
  Для внутренней аттестации это считается приемлемым.
- **Не работает по сети.** Тестирование идёт на одном компьютере, результаты
  собираются в один файл базы.
