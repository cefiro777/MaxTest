# MaxTest — для разработчиков

Пользователям этот файл не нужен: программа ставится установщиком со
[страницы релизов](https://github.com/cefiro777/MaxTest/releases/latest).

План разработки и отметки о приёмке — в [PLAN.md](../PLAN.md).

## Запуск из исходников

```powershell
python -m venv .venv
.venv\Scripts\pip install -r requirements-dev.txt
.venv\Scripts\python -m maxtest
```

## Тесты

```powershell
.venv\Scripts\python -m pytest
```

## Сборка релиза

```powershell
.venv\Scripts\python -m tools.build_release
```

Скрипт по шагам: иконка → демо-тест → сборка PyInstaller → **проверка
собранного** (`--selfcheck`) → компиляция установщика Inno Setup. Непроверенная
сборка в установщик не попадает.

На выходе:

| Файл | Что это |
|---|---|
| `dist\MaxTest-Setup-<версия>.exe` | Установщик, ~28 МБ |
| `dist\MaxTest-Setup.exe` | Та же сборка с постоянным именем — для ссылки «скачать последнюю версию» |
| `dist\MaxTest\` | Распакованное приложение, ~98 МБ |

Требуется [Inno Setup 6](https://jrsoftware.org/isdl.php). Собрать только
приложение, без установщика: `.venv\Scripts\pyinstaller build\maxtest.spec --noconfirm`.

## Выпуск новой версии

1. Поднять `AppVersion` в `build/maxtest.iss` и `VERSION` в `site/build_page.py`.
2. `python -m tools.build_release`.
3. Опубликовать релиз — **оба** файла, иначе кнопка «Скачать» в README перестанет
   вести на свежую версию:

   ```powershell
   gh release create vX.Y.Z dist\MaxTest-Setup-X.Y.Z.exe dist\MaxTest-Setup.exe --repo cefiro777/MaxTest
   ```

## Где что лежит

| Путь | Что это |
|---|---|
| `maxtest\core\` | Модель, формат `.qtest`, оценка, хранилище. Без PyQt — покрыто тестами |
| `maxtest\ui\` | Окна: стартовое, конструктор, проигрыватель |
| `samples\demo.qtest` | Демо-тест (`python -m tools.make_demo` пересобирает) |
| `site\` | Исходники сайта infomaxtest.ru (`python site/build_page.py`) |
| `%APPDATA%\MaxTest\` | Результаты (`results.db`), бэкапы, логи, папка тестов |

Папку данных можно переопределить переменной окружения `MAXTEST_DATA_DIR`.

## Устройство

* Формат теста `.qtest` — zip: `manifest.json` + `media/`, атомарное сохранение
* Хранилище — SQLite, ежедневный автобэкап, снимки ответов для протоколов
* Диагностика собранной программы: `MaxTest.exe --selfcheck`
